# Python Mini Games Website

A browser-playable Streamlit app featuring Snake, Water, Gun and Number Guessing.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy for free

1. Upload this folder's files to a GitHub repository.
2. Open https://share.streamlit.io/ and sign in with GitHub.
3. Choose **Create app**, select your repository and branch, and set the main file path to `app.py`.
4. Click **Deploy**.
